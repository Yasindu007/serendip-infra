# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, welcome newcomers, and keep
criticism about the work, not the person. Harassment of any kind isn't
accepted.

Report unacceptable behaviour privately to the maintainers through
[a security advisory](https://github.com/Serendip-Infra/serendip-infra/security/advisories/new)
(it reaches the maintainers only) or by email to the address on the
[Serendip-Infra organisation](https://github.com/Serendip-Infra) profile.
Reports are kept confidential.
